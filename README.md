# NA Scoliosis Foundation Website Improvement (Team A)

## About the project
A short description: we're improving the website of the NA Scoliosis Foundation NPC/NPO
(https://nascoliosis.co.za) as part of our cohort. This repo holds our research,
planning notes, and evidence.

## About the organisation
a non-profit founded by twin sisters Nashley and Nadia Adams to
support people with scoliosis and raise awareness.

## Goal
What the team wants to achieve, e.g. make the website clearer, more trustworthy,
and easier to use for donors, volunteers, and patients and families.

## Tech Stack
- **Frontend:** Semantic HTML5, CSS3 (Custom Properties for Light & Dark modes), Vanilla JavaScript
- **Architecture Spec:** See [`docs/architecture.md`](docs/architecture.md) 

## Folder Structure
- `index.html` — Root entry point (redirects to `pages/Home/index.html`)
- `assets/` — Shared CSS design tokens (light/dark mode), global layout styles, JS navigation/theme toggle, and images
- `pages/Home/` — Landing page (Hero, Who we are, 3 Action Cards, Voices that light the way, Join us, Footer)
- `pages/About/` — Our story, Mission & vision, What we do
- `pages/Support/` — Get involved, Voices of hope , Gifts of hope , Resources 
- `pages/News and Events/` — News  Events  Monthly updates
- `pages/Contact us/` — Ways to reach us
- `pages/Donate/` — Donation hub, One-off, Sponsorship
- `pages/Legal/` — Terms of Use, Privacy Policy
