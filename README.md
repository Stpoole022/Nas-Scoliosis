# NA Scoliosis Foundation Website Improvement (Team A)

## About the project
A short description: we're improving the website of the NA Scoliosis Foundation NPC/NPO
(https://nascoliosis.co.za) as part of our cohort. This repo holds our research,
planning notes, and evidence.

## About the organisation
a non-profit founded by twin sisters Nashley and Nadia Adams to
support people with scoliosis and raise awareness.

## Goal
What the team wants to achieve, e.g. make the website clearer, more trustworthy,
and easier to use for donors, volunteers, and patients and families.
